Backend Stack · Top 5 Repos to Clone

Agent Orchestration Layer

These five repos give you the entire backend. Clone in this stack-rank order. Modify, don't build from scratch.
A1. CopilotKit/CopilotKit
★ 30.5k · MIT · github.com/CopilotKit/CopilotKit
Frontend protocol layer. Ships the AG-UI Protocol — streaming agent state, tool calls, intermediate steps from any backend (LangGraph, ADK, custom) into a React frontend. Adopted by Google, Oracle, LangChain. Provides useCoAgent, useCoAgentStateRender, human-in-the-loop, generative UI. Study first: examples/coagents-research-canvas/ — full-stack LangGraph + CopilotKit canvas, mirror of demo shape. Integration: ~4 hours baseline, ~1 day for routing visuals.
A2. langchain-ai/langgraph + langgraph-supervisor-py
★ 30.9k · MIT · github.com/langchain-ai/langgraph
Orchestration backbone. The supervisor pattern maps 1:1 to "CEO agent → department agents". Built-in checkpointing, streaming events (stream_mode="values" / "updates" / "messages"), human-in-the-loop, time-travel debug. LangGraph Studio gives a free graph visualizer you can secondary-screen on stage. Study first: langgraph-supervisor-py/README.md — supervisor primitive in 30 lines. Integration: ~6-10 hours.
A3. anthropics/claude-agent-sdk-demos
★ 2.3k · MIT · TS 88% Python 9%
Anthropic's reference patterns. The research-agent/ demo is a CEO-orchestrator-routes-to-subagents demo with parallel research workers. Uses AgentDefinition, SubagentTracker, HookMatcher — exact primitives needed to track and stream subagent activity. simple-chat-app/ shows React + Express + WebSocket streaming. Integration: ~2 hours to clone, ~1 day to fork the orchestrator pattern.
A4. assistant-ui/assistant-ui
★ 9.8k · MIT · 200k monthly downloads
Streaming chat primitives. Streaming, auto-scroll, tool-call rendering, voice dictation, accessibility, retries — chat-UX details that eat 2 days when you build them yourself. Integrates natively with Vercel AI SDK, LangGraph, AND Mastra. Used by LangChain, Stack AI, Browser Use. Composable shadcn-style primitives. Use it for the chat column; CopilotKit for the agent state column. Don't run both chat shells.
A5. openai/openai-realtime-agents
★ 6.8k · MIT · Next.js + WebRTC
Voice front-end reference. The cleanest open-source pattern for browser-native voice agents with WebRTC. Includes the Chat-Supervisor pattern (small realtime model for fast voice + bigger model for reasoning) and Sequential Handoffs. Use front-end voice but route the transcribed intent to your Claude orchestrator — don't lock the show to OpenAI's runtime. Critical: use push-to-talk on stage. Open-mic VAD + audience laughter = chaos. Volunteer holds spacebar.
★ Why Not the Alternatives

Not OpenAI Agents SDK as orchestrator — breaks the "Claude-powered" narrative. Use only for voice front-end.

Not CrewAI — inter-agent state is fuzzy and hard to visualize live. Audience needs to see deterministic routing.

Not AutoGen — debate-style agent loops blow latency. 4-agent debate × 5 rounds = 20+ LLM calls = 30s silence on stage.

Not Mastra — beautiful TS framework, but LangGraph + CopilotKit ecosystem has tooling Claude Code can scaffold fastest today.

Key Data Flows

  1. Volunteer holds spacebar → mic → OpenAI Realtime returns transcribed text
  2. Transcribed intent POSTed to FastAPI bridge /api/run
  3. FastAPI invokes LangGraph supervisor with the intent
  4. CEO agent decides routing, calls route_to_marketing (or multiple in parallel)
  5. Each tool call streams update events back via AG-UI SSE
  6. CopilotKit useCoAgentStateRender lights up the right node in React Flow
  7. Specialist agents stream their token output to the chat panel
  8. CEO synthesizes and returns final response
★ Two Day-0 Decisions to Lock

1. Polyglot vs. TS-only? Polyglot (Python backend + TS frontend) wins because LangGraph Studio's graph visualizer is too valuable to give up. Recommendation: polyglot.

2. Self-host CopilotKit runtime vs. Cloud? Self-host on Vercel — one fewer external dependency on demo day. Recommendation: self-host.

The 14 Rules · Tron vs Amateur

Make It Look Real

These are the things that separate Tron from Kid's Show. Every rule is one specific implementation. No vague "use good design."
RULE 1
Three-layer depth — always
Every frame has 3 z-depths: Foreground (z:100, sharp, full opacity, full saturation), Midground (z:50, opacity 0.4-0.6, slight blur), Background (z:0, opacity 0.1-0.2, heavy blur, desaturated).
RULE 2
Glow falloff — never single box-shadow
Bad: box-shadow: 0 0 20px cyan = Geocities. Good: layer 3 stacked shadows mimicking real light bloom. Better: R3F Bloom on emissive material with intensity >1.
RULE 3
Easing curves — never linear, never default ease-in-out
Default UI: cubic-bezier(0.16, 1, 0.3, 1) (expo out). Critical moments: cubic-bezier(0.87, 0, 0.13, 1) (expo in-out, "fluid intelligence"). Never Tailwind's transition-all.
RULE 4
Opacity rhythm — never 100% on text below the fold
Active panel headline 100%, body 80%, labels 60%. Adjacent panel everything 50% × those values. Breathable hierarchy without changing color.
RULE 5
The Ambient Text rule (Jayse Hansen's secret)
Iron Man HUD looks alive because of UNREADABLE micro-text everywhere. Ring of tiny rotating coordinates, numerical readouts updating every 200ms with random-but-bounded values, glyphs at periphery. None means anything. Sells "this is alive."
RULE 6
Every interactive element has 3 states + hover bleed
Idle (60% opacity, soft glow), Hover (100%, brighter glow, +1% scale, soft comms sound at 0.2 vol), Active (100%, full glow, slight rotation 1deg, confirm sound). Press → release has 200ms decay where glow dims back.
RULE 7
Neon palette discipline
Pick exactly 2 neons. Cyan #00d4ff for "alive", Amber #ffa500 for "alert/active". Everything else grayscale. Third neon = Christmas tree. Brief red flash for error only as momentary state.
RULE 8
Frame chrome is structural, not decorative
Use Arwes <FrameSVGOctagon> or hand-built SVGs. The 45° chamfer at top-right and bottom-left reads as "engineered," not "rectangular box." Without this, your panels look like Bootstrap cards.
RULE 9
The 1.5× animation rule
Motion that feels right at 1.0× in dev tools feels rushed on stage. Build with globalMotion = 1.5 multiplier and tune. Audience needs reaction time.
RULE 10
Negative space audit
At any moment, ≥40% of screen is dark/empty. If full of panels, cut. Blade Runner 2049 has shots where 80% of frame is black. Eye needs rest to register magic.
RULE 11
Sub-pixel grid alignment
Every element on a 4px grid (Tailwind defaults match). Misaligned by 2px = amateur dashboard. Use grid and gap-4 everywhere.
RULE 12
Don't animate everything at once
Stagger. 3 panels appear at 0ms, 150ms, 300ms — not all together. Apply to every group of >1 element. Motion's staggerChildren makes this trivial.
RULE 13
Sound timing locks visual
Bleep that fires JUST BEFORE visual change makes change feel decisive. playSound('confirm'); setTimeout(triggerExpand, 60). 60ms head-start makes press feel like it CAUSED expansion.
RULE 14
Backdrop video tricks
Higgsfield/Seedance clips with mix-blend-mode: screen or lighten and opacity 0.12-0.18 lets cinematic energy bleed through without competing with UI. NEVER full opacity behind UI — eats contrast.

Risks & Mitigations

What Will Go Wrong

Plan for failure. Have a recovery for every plausible disaster. The kill-switch has saved more demos than any retry logic.
RiskLikelihoodImpactMitigation
Voice fails in noisy room High Show-stopper Push-to-talk only. Pre-test with 80dB noise loop. Hidden Cmd+T fallback. Don't use open-mic VAD on stage.
Anthropic API rate-limit / outage Medium Show-stopper Pre-cache prompts. Recorded video fallback for each segment. Tier 4+ account.
Inter-agent latency >20s Medium Pacing kill Sonnet 4.5 (2× faster than 4.0). Haiku 4.5 for routing if too slow. parallel_tool_calls. Pre-warm with no-op call on entry.
WebSocket / SSE drops mid-demo Low Visible glitch Vercel HTTP/2 SSE. Test on hotel WiFi. Hotspot backup.
CopilotKit + assistant-ui collision Medium Build delay Pick ONE chat shell on Day 1. Don't run both.
LangGraph supervisor loops / hallucinates routing Low-Med Wrong department fires Add routing_confidence field. If <0.7, default to "general" + ask. Pre-script 3 demo intents, bake routing via few-shot.
Agent produces bad/embarrassing content live Low-Med Brand risk Content validator step (Haiku checks length + no profanity). Pre-script demo prompts to known-good output range.
Over-engineering visualization High Time sink Day 3 boxed at 1 day. If React Flow is fighting you by lunch, fall back to CSS Grid + motion-react and ship. Audience cares about story, not prettiness.
Vendor lock-in to OpenAI for voice Low Narrative ding Voice is just transcription, not reasoning. Pitch is "Claude reasoning, OpenAI ears." Swap to Pipecat + Deepgram in 1 day post-show if needed.
Polyglot deployment friction Medium Day 7 hassle Vercel for frontend, Railway/Fly for Python backend. OR use AI SDK's TS-native ToolLoopAgent (loses LangGraph Studio).
★ The Kill-Switch (Build This Day 7)

Bind Esc to a state that fades all panels out and shows just the CEO core with one line: "SYSTEM IDLE". If anything goes wrong on stage, you press Esc, the visual stays intentional, and you say "Let's pause here."

This has saved more demos than any retry logic.

★ The Fake-Mode Toggle

Build both modes. Default to fake mode for stage (deterministic, instant, no API failures). Use real mode in green room to record live demo for highlight reel.

Pre-recorded responses played token-by-token via flowtoken look identical to live. Audience cannot tell.
